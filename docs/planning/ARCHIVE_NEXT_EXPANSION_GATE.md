# Archive Next Expansion Gate

## Purpose

Before adding new archive content, run expansion decisions through the current smoke checklist and narrative system constraints.

This prevents new content from breaking:
- archive-first onboarding
- artifact handling rhythm
- emotional pacing
- readability hierarchy
- preservation ethics
- the set-object-down loop

## Required Pre-Expansion Check

Before implementing a new artifact, reveal, or document cluster:

1. Read `docs/qa/ARCHIVE_ROUTE_SMOKE.md`.
2. Identify which existing route or system the new content touches.
3. Confirm the addition does not bypass the archive desk.
4. Confirm the addition does not expose private material too early.
5. Confirm the addition preserves the physical handling metaphor.
6. Confirm the addition has a clear emotional escalation purpose.
7. Confirm the addition does not turn the archive into a generic lore browser.
