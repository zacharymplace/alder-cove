# Archive Access & Inspection Structure

The archive is not a content browser. It is a preservation environment.

The player should feel like they are:
- requesting access to preserved material
- handling unstable artifacts
- deciding how deeply to inspect
- crossing emotional boundaries gradually

## Archive Index

Documents may be:
- shared
- semi-private
- private
- illicitly acquired

The player should eventually ask:

> Why do I have this?

not only:

> What does this mean?

## Inspection Flow

1. Archive index
2. Document handling state
3. Two-page spread view
4. One-page focus view
5. Sustained inspection
6. Provenance/wording drift

## Design Rule

Artifacts should feel emotionally human, physically handled, ethically complicated, and psychologically survivable.
