# Archive Document System

## Purpose

Alder Cove should not treat every artifact as equally public.

The archive needs document-level ethics so the player can slowly question not only what a document says, but whether they should be reading it at all.

## Initial Document

`notebook-one-shared`

This is the shared group notebook.

It can safely contain:
- maps
- group rules
- check-in logic
- shared dares
- copied public fragments
- group-authored memory

But even shared artifacts can become ethically unstable when:
- copied later
- reconstructed after damage
- softened by shame
- handled by someone outside the original group

## Access Classes

### Shared

Intended for group use.

### Semi-private

Shared with one or two people, but not the whole group.

### Private

Never meant to be archived publicly.

### Illicitly acquired

The archive has it, but probably should not.

## Core Design Rule

A document's access class should affect how the player feels before it affects mechanics.

The player should eventually ask:

> Why do I have this?

not only:

> What does this mean?

## Emotional Direction

The archive is not a villain system.

It is a survival system built by emotionally compromised people trying to preserve versions of memory they can live with.

---

## Withheld Readability

Some documents should exist in the archive before they become readable.

This creates:
- ethical hesitation
- emotional anticipation
- preservation tension
- respect for boundaries

The player should sometimes encounter:
- physically preserved material
- cataloged fragments
- handling notes
- restoration residue

without immediate textual access.

The archive can preserve presence before preserving legibility.
